## 原文引用

> 那次聚会持续了 1 小时，我被他们的谈话震惊了，因为他们所谈的内容几乎就是我的交易。
>
> 他们谈论的是酒精，但只要我用“损失”替换“酒精”二字，他们所说的大部分内容就能用到我的交易过程中去！我的资本金在这些天也不断地赔赔赚赚，那次聚会之后我感觉到我必须像戒酒协会的成员对待酗酒那样对待自己的亏损。

## 一、匿名戒酒会（AA）是什么、运作模式、为什么能戒瘾

### 1. AA 基础背景与组织形式

嗜酒者互诫协会（Alcoholics Anonymous，AA）于 1935 年在美国创立，是全球最早、规模最大的 **peer（同伴）自助康复小组**：

1. **核心规则：匿名、免费、自愿**
   * 全程匿名：会上所有分享不外传，保护羞耻感，不用担心被评判、曝光；
   * 无收费、无专业医师授课：组织者、分享者全是**正在戒酒/已经戒酒成功的成瘾者**，没有医生、咨询师主导；
   * 来去自由，不强制约束，只依靠自我意愿参与。
2. **聚会标准流程**
   几十人围坐，轮流分享自身经历：过去酗酒失控、否认问题、跌到谷底、如何反复复饮、十二步如何帮助自己；不评判、不给说教，只讲自己真实的痛苦与挣扎，他人只倾听。
3. **两大核心体系**
   * **十二步骤**：个人改变的完整心理行动指南（埃尔德重点借鉴）；
   * **十二传统**：维持小组纯粹互助氛围的组织准则，杜绝商业化、个人崇拜。

### 2. AA 能战胜成瘾（药物、酒精）的 4 个核心底层逻辑

#### （1）第一步先击碎「否认心理」，直面失控（最关键）

成瘾者第一本能是否认问题：“我只是偶尔喝点，我能控制”；心理咨询容易被来访者的谎言、自我欺骗蒙蔽。

AA 十二步第一条直接强制认知：**承认我们对酒精无能为力，生活已经彻底失控**。

只有承认“单靠意志力我管不住自己”，才会放弃幻想，愿意寻求外部约束。

#### （2）消解孤独与羞耻，打破自我封闭循环

酗酒者大多独自躲起来喝酒，不敢和家人朋友倾诉，羞耻感会加剧逃避、更依赖酒精麻痹自己。

AA 所有人拥有同样的痛苦经历，不存在居高临下的说教：你不用伪装强大，所有人都懂你的失控、崩溃、反复失败。孤独感消失，就不需要靠成瘾行为逃避情绪。

#### （3）不靠单纯意志力硬扛，用外部社群 + 标准化步骤建立约束

传统精神治疗、药物只能短期让人清醒，离开诊所后，独自面对压力很容易复发——**意志力单独对抗本能成瘾几乎必败**。

AA 提供两套外部支撑：

* 同伴监督：你有专属“导师（sponsor）”，情绪躁动、想要复饮时可以立刻找人倾诉；
* 十二步标准化流程：每日自我反省、持续复盘错误、主动弥补过错，把无意识的强迫性重复拉到意识层面。

#### （4）利他闭环：帮助别人，治愈自己（第十二步）

戒酒成功的人必须持续去新的小组分享、帮助新人。

心理学机制：当你去共情、开导同样深陷泥潭的人，你会跳出自我自怜、自我毁灭的思维；通过帮助他人巩固自己的清醒状态，获得稳定的价值感，不再需要酒精提供短暂快感。

## 二、埃尔德的核心类比：把「酒精」替换成「亏损」，交易者和酗酒者是同一种成瘾逻辑

埃尔德参加 AA 聚会的最大冲击：两者底层心理、行为循环 100% 重合，这也是他引入 AA 理念改造交易心态的根本原因。

### 1. 酒精成瘾 vs 亏损交易成瘾

| 酗酒者特征                   | 亏损交易者完全相同的表现                  |
| ----------------------- | ----------------------------- |
| 否认：坚称自己能控制饮酒，只是偶尔小酌     | 否认：坚信自己能控制交易，亏损只是运气差，自己不会上瘾   |
| 失控：一旦开始喝酒，没有止损，越喝越多     | 失控：开仓后不止损，浮亏加仓报复性交易，越亏越重仓     |
| 间歇性多巴胺刺激：偶尔微醺的快感掩盖长期伤害  | 多巴胺驱动：偶尔一次大盈利带来强烈刺激，忽略无数次持续亏损 |
| 跌到谷底才愿意承认问题，之前持续自我欺骗、甩锅 | 爆仓、大额回撤后才反思，此前全部归咎行情、软件、消息    |
| 独处时容易复发，空虚、焦虑就想喝酒逃避现实   | 无聊、焦虑、压力大就强行开仓，用交易刺激填补内心空洞    |
| 强迫性重复：发誓戒酒，遇到情绪刺激再次破戒   | 强迫性重复：发誓不再重仓扛单，行情波动又重复相同错误    |

### 2. 神经科学底层同源（为什么意志力没用）

酒精、短线交易都会持续刺激大脑多巴胺奖赏回路：

1. 酒精直接提升多巴胺；
2. 交易的不确定性（涨跌未知）会产生**可变比率强化**，大脑对这种**随机刺激**极度上瘾，哪怕十次亏九次，一次盈利就会牢牢记住快感。

两者都属于**强迫性成瘾行为**：理性明明知道会毁灭生活，但潜意识、生理欲望会驱动人重复伤害自己，也就是前文提到的「自毁倾向、明知错误仍重复」。

### 3. 为什么普通心理治疗对酒鬼/亏损交易者效果有限？

1. 心理咨询容易纵容交易者的自我美化、外部甩锅；
2. 单独复盘、独自交易，没有外部力量打破你的否认、侥幸；
3. 交易者独自面对盘面时，情绪会瞬间吞噬理性，没有即时倾诉、叫停的渠道。

就像酒鬼戒断后独处往往复饮，交易者独自盯盘极易失控。

## 三、埃尔德如何借鉴 AA 互助小组、十二步原则改造交易？

埃尔德没有让交易者组建线下互助会，而是提取 AA 核心精神，做成交易者个人专属的「心理安全网」，分为四层落地方法：

### 1. 借鉴AA核心精神一：彻底放弃“我能完全靠自己控制市场”的幻想（对应十二步第一步）

绝大多数交易者致命幻觉：我足够聪明、有技术，我可以掌控行情。

对应 AA 的“承认无力”，交易者必须承认：**仅凭自己的情绪、意志力，无法对抗贪婪、恐惧、侥幸**；市场波动、自身心理缺陷是自己单独驾驭不了的，必须依靠外部规则约束（资金管理、交易日志、自我约束流程）。

这也是埃尔德反复强调 2% 风控法则的根源：相当于酒鬼给自己设定“绝对不碰酒”的硬性底线。

### 2. 借鉴 AA 核心精神二：持续、坦诚、无美化的自我复盘（对应第四步、第十步）

AA 要求成瘾者做全面道德检讨，持续每日自省、有错立刻承认；

落地到交易就是**强制交易日志**：

* 不允许甩锅行情，必须记录自己每一笔冲动、侥幸、自负；
* 定期复盘重复犯错模式，直面自己的自毁行为，击碎一厢情愿的自我欺骗；
* 不美化交易，盈利不夸大能力，亏损不回避自身决策失误。

### 3. 借鉴 AA 核心精神三：建立外部监督与心理缓冲（替代线下互助小组）

普通人很难找到交易者互助小组，埃尔德给出替代方案：

1. 固定复盘搭档：和同样理性交易的朋友定期交流账户、交易心态，互相指出彼此的侥幸、重仓冲动；
2. 设立“暂停机制”：一旦出现连续亏损、想要报复交易，强制停止操作，如同酒鬼有欲望时立刻联系同伴；
3. 公开记录净值曲线，减少自欺欺人的空间（对应 AA 匿名分享，暴露真实困境，不再独自隐瞒亏损）。

### 4. 借鉴 AA 核心精神四：利他思维治愈交易心魔（第十二步）

AA 康复者必须帮助新人，对应交易者：

不要只盯着自己赚多少钱，持续复盘、总结经验分享给其他普通交易者。

当你客观拆解别人的亏损心理陷阱时，你会更清晰看见自己身上相同的弱点，跳出只关注盈亏的贪婪视角，弱化对短期行情刺激的成瘾渴求。

## 总结

1. 前文提到人存在**潜意识自毁、强迫性重复、一厢情愿自我欺骗**，而 AA 模式是经过大量成瘾者验证、专门打破这类心理闭环的工具；
2. 传统技术分析、计算机量化、单纯读书学习，只能解决“怎么看行情”，无法解决“管不住自己”的成瘾问题；
3. 交易亏损本质是**行为成瘾**，和酗酒共用同一套心理、生理机制，光靠提升智力、优化系统永远无法根治；
4. 埃尔德引入 AA 不是玄学，而是作为精神科医生，把成熟成瘾康复体系迁移到交易心理，构建完整的心理安全网，和资金管理、交易日志三者相辅相成，形成稳定盈利的三大支柱（心态、系统、风控）。

酗酒者靠 AA 约束对酒精的渴求，交易者需要借用 AA 的自省、约束、互助逻辑，约束自己对无序交易、赌行情、重仓回本的成瘾冲动，唯有先承认自身失控，才能真正掌控交易。
